# 向北课表岛 Android 版

原生 Android 悬浮窗版本，目标覆盖 Android 8.0 及以上，以及仍支持安装 APK 的 HarmonyOS 4.x 设备。

## 当前功能

- 顶部课表悬浮岛，支持拖动、展开、收起和小圆钮最小化
- 长按悬浮岛（或连接鼠标后右键）打开岛内快捷菜单，无需进入主应用
- 支持“回到今天”，并恢复关闭前的日期、展开/最小化和位置状态
- 进入系统最近任务界面时自动隐藏，离开后恢复
- 可从设置页一键重置悬浮岛位置
- 显示当前课程、下一节课程、时间、地点和倒计时
- 一周七天切换及当天课程列表
- 点击课程卡片显示完整详情
- 导入桌面版 `课表_按日期.csv`
- 同课程同时间的多个实验室记录自动合并
- 前台服务保活、通知栏停止入口和开机恢复

## CSV 格式

```csv
日期,星期,开始,结束,课程,教师,地点,节次,第几周
2026-09-14,周一,08:00,09:40,示例课程,示例教师,教学楼-101,1-2节,1
```

## 权限说明

- `SYSTEM_ALERT_WINDOW`：在其他应用上方显示用户主动开启的课表岛。
- `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE`：持续显示课表岛，并提供常驻运行通知。
- `POST_NOTIFICATIONS`：显示前台服务运行状态。
- `RECEIVE_BOOT_COMPLETED`：仅在用户已经开启课表岛时尝试开机恢复。
- 辅助功能“课表岛最近任务自动隐藏”：仅监听顶层窗口名称，以判断是否进入最近任务；
  `canRetrieveWindowContent=false`，不读取页面节点、输入内容或其他应用正文。此项需要用户手动开启，
  不开启时只有“最近任务自动隐藏”不可用，课表岛的其他功能不受影响。

应用不包含网络权限。

## 构建

在仓库根目录运行：

```powershell
.\build-android.ps1
```

首次使用应准备 JDK 17、Android SDK 35 和 Gradle 8.11.1，或调整脚本中的本地工具路径。
